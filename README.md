# CLIENTOUR

App per la pianificazione dei giri visita: clienti, mappa, agenda ottimizzata, calendario, rapporti e compiti.

- App online: https://andreamuraroxlavoro-wq.github.io/clientour/
- Un solo file (`index.html`), funziona anche offline; i dati restano nel browser del dispositivo e, se attivata, si sincronizzano tramite Google Drive, una cartella sul computer o un server personale (Opzioni → Gestione dati → Sincronizzazione cloud).
- Su iPhone/iPad: Safari → Condividi → *Aggiungi alla schermata Home*. Su Android: Chrome → ⋮ → *Aggiungi a schermata Home*.

Sorgenti e documentazione: cartella «Progetti cowork/CLIENTOUR» (iCloud).
